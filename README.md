 Weather Dashboard

 About the Project

The **Weather Dashboard** is a web-based application that allows users to search for a city and view its weather information.

The project provides a simple and user-friendly interface for checking weather details using HTML, CSS, and JavaScript.

 Objectives


- To provide weather information in a simple way.

- To allow users to search for different cities.

- To create an attractive and easy-to-use weather dashboard.

- To practice frontend web development.

- To understand how JavaScript can be used to handle weather data.

 Technologies Used


- **HTML5** – Creates the structure of the website.

- **CSS3** – Provides styling and layout.

- **JavaScript** – Adds functionality and user interaction.

- **GitHub** – Used for project hosting and version control.

 Features

-  Search weather by city

-  Display temperature

-  Display weather conditions

-  Display humidity

-   Display wind information

-  Easy city search

-  Simple and user-friendly interface

-  Dynamic weather information

Project Structure


 
How It Works


1. Open the Weather Dashboard.

2. Enter the name of a city.

3. Click the search button.

4. The application processes the city name.

5. Weather information is displayed on the dashboard.

 How to Run the Project

1. Clone or download this repository.

2. Open the project folder.

3. Open index.html in a web browser.

4. Enter a city name.

5. View the weather information.
